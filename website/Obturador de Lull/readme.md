# Obturador Lull — Rueda Fotográfica

> Sistema de composición fotográfica aleatoria inspirado en las ruedas de Ramon Llull y el mecanismo de obturación de una cámara. 9 anillos concéntricos independientes, 20 opciones cada uno, 512 billones de combinaciones posibles.

## Descripción

**Obturador Lull** es una herramienta creativa para fotógrafos, directores de arte y estilistas que necesitan romper el bloqueo creativo o explorar combinaciones inesperadas de parámetros fotográficos. Funciona como una rueda de la suerte con 9 anillos concéntricos independientes — cada uno representando un aspecto diferente de una sesión fotográfica:

| # | Anillo | Ejemplo de opciones |
|---|--------|-------------------|
| 01 | **Lugares** | Desierto de sal, Bosque victoriano, Catedral vacía… |
| 02 | **Épocas / Estilos** | Barroco, Cyberpunk, Cine noir, Posthumanismo… |
| 03 | **Modelos + Poses** | Contrapposto, Arrodillada, Saltando… |
| 04 | **Puntos de vista** | Cenital, Nadir, Plano holandés, POV desde dron… |
| 05 | **Iluminaciones** | Luz dura lateral, Contraluz, Luz de vela… |
| 06 | **Técnicas fotográficas** | Larga exposición, Bokeh extremo, Doble exposición… |
| 07 | **Temporalidad** | Amanecer, Hora dorada, Medianoche… |
| 08 | **Estacionalidad** | Invierno, Monzón, Nevada… |
| 09 | **Atmósfera** | Etérea, Espectral, Onírica, Ritual… |

Cada anillo contiene **20 opciones** cuidadosamente redactadas, resultando en **20⁹ = 512.000.000.000** combinaciones posibles.
